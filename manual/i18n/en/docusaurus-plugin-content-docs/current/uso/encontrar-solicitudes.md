---
title: Find an application
sidebar_label: Search and filter
---

In **Applications** you can combine:

- **Search** by position or company (**Search position or company…**).
- **Filters** by status, work mode and source.
- **Archived**: Active (default), Archived, or Active and archived.
- **Sort**: by application date, last update, company or position, in either direction.

**Clear filters** takes you back to the initial view. The list shows 20 applications per page.

To see all the applications for a company, go to **Companies** and click its number of **Applications**.

:::tip Filters live in the page address
Search, filters, sorting and page are kept in the URL. You can bookmark it to come back to the same view, and the browser's **back** button undoes the last filter change.
:::
