---
title: See your interviews and reminders in a calendar
sidebar_label: Calendar
---

**Calendar**, in the menu, puts the [interviews](entrevistas.md) and [reminders](recordatorios.md) of all your applications in one place.

## What shows up

- Interviews with any result except **Cancelled**.
- **Pending** reminders, including overdue ones (in red, with the **Overdue** label).

Cancelled interviews and reminders that are done or dismissed do not appear. Notes are never shown.

## Month and week

The **View** selector switches between **Month** and **Week**. The **Today**, **Previous month** / **Next month** (or **Previous week** / **Next week**) buttons move you through time. The view and the day you are on are kept in the page address, so you can bookmark it.

- **Month**: a Monday-to-Sunday grid, with up to three events per day. If there are more, **N more** opens that week. On a phone it appears as an agenda with only the days that have something.
- **Week**: the seven days, with all their events.

Click an event to go to its application. A reminder with no linked application takes you to **Reminders**.

## Time zone

Times are shown in your account's time zone, as stated by the text **Times in** followed by the zone. If your account has none saved, your browser's is used. To change it, go to [Preferences](preferencias.md).

## Add an event to another calendar

In the **Week** view (and in the phone agenda), each event has the **Add to calendar** menu. You also find it on interviews and on pending reminders inside an application, and on the **Reminders** page. It offers two options:

- **Google Calendar**: opens Google Calendar with the event already filled in; you only have to save it.
- **Download .ics**: downloads a file you can import into Outlook, Apple Calendar, Google Calendar, Thunderbird and most calendars.

The event carries the title, the time, the duration, the type and format (for an interview), the interviewers and a link to the application. An interview lasts what you entered, or 60 minutes if you left the duration empty; a reminder lasts 15 minutes. Notes are never included.

:::caution It is a copy
The event you add is not kept up to date: if you later change the date or time in the application, the calendar where you saved it does not find out. With the **.ics**, importing the file again updates the event you already had. With **Google Calendar**, a new event is created each time, so delete the previous one.
:::

The application does not offer an automatic calendar subscription.
