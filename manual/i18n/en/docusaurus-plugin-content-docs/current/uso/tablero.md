---
title: See your applications on a board
sidebar_label: Board
---

In **Applications**, the **List** / **Board** switch next to the title changes the view. The board shows one column per [status](seguir-el-estado.md), in the order of the process, with the number of applications in each.

Each card shows the position, the company and how many days the application has been in that status. Click the position to open the application.

A column shows the 50 applications that most recently entered that status. If it has more, **and N more in the list** appears at the bottom and opens the list filtered by that status.

## Move a card by dragging it

Drag the card by its handle (the dots on the left) and drop it in another column. While you drag, the columns that application cannot move to are dimmed: the board follows the same rules as **Change status**.

When you drop it, the status changes right away, dated now and without a note. A message with **Undo** stays for a few seconds, in case you dropped it in the wrong place.

With the keyboard: move the focus to the handle, press **Space** to pick it up, move it with the arrow keys and press **Space** again to drop it (or **Escape** to cancel). A screen reader announces each step.

## Move a card with the menu

The arrows button on each card opens **Move to…**, with the statuses it can move to. Choosing one opens the same dialog as in the application, with that status already set: there you can change **When it happened** and write a note before clicking **Change status**.

Use the menu when you want to leave a note or record something that happened on another day. For a quick change, drag.

## Collapse the final columns

Accepted, Rejected and Withdrawn have a button to collapse them: they shrink to a narrow strip with their number of applications, and you can still drop cards on them. The board remembers in this browser which columns you collapsed.

Applications in a final status have no handle and no menu: from there they cannot move to another status.

## Filters

The board uses the same search and the same status, work mode and source filters as the list ([Search and filter](encontrar-solicitudes.md)), and they are kept when you switch views. It does not show archived applications and has no sort order of its own.
