---
title: Add an application
---

An application is a candidacy for a specific position at a company.

## Steps

1. In **Applications**, click **New application**.
2. In **Company**, start typing the name:
    - if it already exists, pick it from the list;
    - if it is new, choose **Create “name”** and it is created on the spot, without leaving the form.
3. Enter the **Position**.
4. Choose the **Status** it starts with:
    - **Saved**: you are interested, but have not applied yet;
    - **Applied**: you have already sent it. In that case, set the **Applied on** date (today by default).
5. Fill in whatever else you want and click **Create application**.

Only the company and the position are required.

## Optional fields

| Field | What for |
|---|---|
| Location | City or region of the position |
| Work mode | On-site, Hybrid or Remote |
| Source | Where you found the job: LinkedIn, InfoJobs, Indeed, company website, referral, recruiter or other |
| Job posting | Link to the ad (must start with `http://` or `https://`) |
| Gross annual salary | Minimum and maximum, in EUR, USD, GBP or CHF. The minimum cannot be higher than the maximum |
| Notes | Free text, up to 5,000 characters |

## Edit an application

Open the application (**View details**) and click **Edit**. You can change everything **except the status**, which has its own action: see [Track an application's status](seguir-el-estado.md).

## Companies

Companies are created automatically when you add applications, but you can also manage them in **Companies**: create them with **New company**, edit their name, website and location, and search them by name. The **Applications** column shows how many each one has; clicking it lists those applications (archived ones included).

Two companies in the same account cannot have the same name.

:::info Limits
Each account can hold up to 5,000 applications and 2,000 companies.
:::
