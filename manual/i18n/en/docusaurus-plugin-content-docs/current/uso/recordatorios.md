A reminder is something you have to do before a date: "write to the recruiter", "prepare the technical test".

## Create a reminder

You can create one from two places:

- **From an application**: open it and click **New reminder** in its reminders section. It is linked to that application.
- **From Reminders**: click **New reminder**. You can search for an application to link it to, or leave it **Not linked to an application**.

Enter the **Title** and the **Due date**, and click **Save**.

## When the time comes

- **Mark as done** once you have done it.
- **Dismiss** it if it is no longer needed.

A pending reminder whose date has passed is shown as **Overdue**. Reminders cannot be edited or deleted: if the date changed, dismiss the old one and create a new one.

## Where to see them

- In **Reminders**, with a status filter: Pending, Done, Dismissed or All.
- In each application's details, its own reminders.
- On the [Dashboard](dashboard.md), the pending and overdue ones.

:::note
Reminders are shown in the application: for now they are not sent by email.
:::

:::info Limit
Up to 500 pending reminders per account. Done and dismissed ones do not count.
:::
