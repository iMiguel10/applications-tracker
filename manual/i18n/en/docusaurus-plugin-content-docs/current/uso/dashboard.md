The **Dashboard** sums up your search in six blocks:

| Block | Shows |
|---|---|
| Applications by status | How many you have in each status right now, archived ones excluded |
| Applications sent per week | How many you sent each week over the last 12 weeks, archived ones included |
| Response rate | Which share of the applications you sent reached **Screening** or beyond |
| Upcoming interviews | The next scheduled interviews |
| Pending reminders | Pending and overdue ones, with a **View all** link |
| No activity | Applications that have not moved for a while |

The lists show the first items and how many more there are.

## Reading the response rate

It is calculated over the applications you sent, and the block says over how many. With **fewer than 5 sent** it shows no percentage, because it would mean nothing: you will see "Not enough data".

## "No activity" does not mean rejected

An application appears here if it is Applied, Screening, Interviewing or Offer and has had no activity **for more than 14 days**: no status changes and no new interviews. You can change that number in [Preferences](preferencias.md).

The application **never assumes** a candidacy was rejected: it only knows what you record. A company that did not answer and an application you did not update look the same. If the process is over, close it yourself with **Change status**.

:::tip
The metrics are only as good as your records. If you record status changes with their real date (**When it happened**), applications per week and the response rate reflect what actually happened.
:::
