---
title: Track an application's status
sidebar_label: Change the status
---

Every application has a status, and every change is kept in its **Status history**.

## The statuses

| Status | Means |
|---|---|
| Saved | You are interested, but have not applied yet |
| Applied | Application sent, no answer yet |
| Screening | The company has answered: first contact or initial test |
| Interviewing | Interview process under way |
| Offer | You have an offer |
| Accepted | You accepted the offer. **Final** |
| Rejected | The company turns you down, or you decline the offer. **Final** |
| Withdrawn | You leave the process. **Final** |

## Change the status

1. Open the application and click **Change status**.
2. Choose the **New status**. Only the ones that make sense from the current status are offered (see the table below).
3. In **When it happened**, leave **Now** or pick the real date if you are recording something that happened earlier.
4. Optionally add a note (for example, "declined the offer because of the salary").
5. Click **Change status** to confirm.

If you move to **Applied** an application that had no application date, it is set to the date of the change.

The date of a change cannot be in the future or earlier than the last recorded change: the history always moves forward.

### From each status you can move to

| From | To |
|---|---|
| Saved | Applied, Withdrawn |
| Applied | Screening, Interviewing, Rejected, Withdrawn |
| Screening | Interviewing, Rejected, Withdrawn |
| Interviewing | Offer, Rejected, Withdrawn |
| Offer | Accepted, Rejected, Withdrawn |
| Accepted, Rejected, Withdrawn | None: they are final statuses |

- You can **skip** statuses forward: from Applied to Interviewing, if the company did no screening.
- You **cannot go back**. If you made a mistake, undo the last change (below).
- If a company reopens a closed process, add a new application or undo the closing change.

## Undo the last change

To fix a mistake, click **Undo last change** in the history and confirm. That change disappears from the history and the application goes back to its previous status.

Only the most recent change can be undone, and never the initial status the application was created with.
