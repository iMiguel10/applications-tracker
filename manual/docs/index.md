Applications Tracker registra cada solicitud a un puesto de trabajo y cómo avanza: sus cambios de estado, sus entrevistas y lo que toca hacer después, para que ninguna candidatura se quede olvidada.

Este manual tiene tres partes, según lo que vengas a hacer:

| Parte | Para quién | Qué encontrarás |
|---|---|---|
| [Uso](uso/primeros-pasos.md) | Quien usa la aplicación | Cada tarea explicada paso a paso: registrar una solicitud, cambiar su estado, programar una entrevista… |
| [Despliegue](despliegue/index.md) | Quien instala y mantiene una instalación | Desplegar con o sin Coolify, variables de entorno, cuentas, correo, IA, copias de seguridad y despliegue continuo |
| [API](api/guia.md) | Quien integra otro sistema | Autenticación, errores y paginación, y la referencia completa de cada endpoint |

:::note Lo que describe este manual
Solo lo que la aplicación hace hoy.
:::
